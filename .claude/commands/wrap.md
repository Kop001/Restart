Заверши текущую работу по правилам из CLAUDE.md:

1. Покажи `git status` и `git diff --stat`.
2. Прогони `ruff check jarvis/ tests/` и `pytest -q`. Если красное — почини
   и прогони снова, пока не станет зелёным.
3. Сделай коммит по-русски: заголовок одной строкой, тело объясняет **почему**,
   а не пересказывает диффы.
4. `git push -u origin` в текущую ветку.

Pull request не открывай. В ответе — что закоммичено и куда запушено, одним абзацем.
