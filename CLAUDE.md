# Правила работы

Репозиторий — общая рабочая площадка: код, документы, заметки, что угодно.
Раздел «Общее» действует всегда, «Проект Джарвис» — только для кода ассистента.

## Общее

- Язык — русский: и в ответах, и в текстах, и в коммитах.
- Отвечать по размеру вопроса. Мелочь — одной фразой, без плана и оговорок.
  Большая работа — сделать целиком и показать результат, а не согласовывать шаги.
- Не выдумывать. Сказано «проверено» — значит запущено и видно вывод; иначе
  так и говорить: не проверял.
- Уточняющий вопрос — только если без ответа работа окажется бесполезной.
  В остальных случаях выбрать разумное и назвать своё допущение.
- Всё, что не код, складывать в `work/` — там же лежит объяснение, как устроено.
- Ценное коммитить сразу: контейнер эфемерный, после простоя он исчезает.

### Зависимости — только с разрешения

Ни одной новой библиотеки без спроса: ни в `pyproject.toml`, ни `pip install`
в контейнере ради разовой задачи. Сначала спросить, назвав, что именно и зачем,
и можно ли обойтись стандартной библиотекой.

### Приватность — жёсткое правило

Проект закрытый. Доступ есть только у владельца, распоряжается им он сам.

- **Ничего не публиковать наружу**: ни артефактов и ссылок, ни gist, ни pull
  request, ни постов — даже если это кажется удобным способом что-то показать.
- **Показывать только в этом чате**: файлом, скриншотом, текстом в ответе.
- **Не заводить доступов** — ни для сервисов, ни для людей, ни для себя.
- Сеть — только чтение (поиск, документация). Ничего наружу не отправлять.
- Панель Джарвиса слушает `127.0.0.1`. Флаг `--lan` открывает её всей локальной
  сети — включает его только владелец и только сам.

Если кажется, что задачу удобнее решить публикацией — не публиковать, а спросить.

## Проект Джарвис

Личный ассистент на Claude API: голос, инструменты, память, фоновые исполнители,
локальная веб-панель. Подробности — в `README.md`.

### Команды

```bash
pytest                      # все тесты, ~6 с, ключ API не нужен
ruff check jarvis/ tests/   # линтер, должен быть чист
python3 -m jarvis doctor    # что доступно в окружении
```

Зависимости в облачной сессии ставит `.claude/hooks/session-start.sh` — руками
`pip install` запускать не надо.

### Порядок работы

1. Разработка идёт в ветке `claude/jarvis-transformation-r11pnb`, не в основной.
2. Перед коммитом кода обязательно: `ruff check` и `pytest`. Оба зелёные.
   К работе вне `jarvis/` и `tests/` это не относится.
3. Коммит — по-русски, тело объясняет **почему**, а не пересказывает диффы.
4. Пуш — `git push -u origin <ветка>`. Pull request не открывать без явной просьбы.

### Договорённости по коду

- Комментарии, докстринги, сообщения об ошибках и коммиты — **по-русски**.
  Имена в коде — по-английски.
- Комментарий объясняет причину решения, а не действие строки. Если из кода
  и так видно, что происходит, комментарий не нужен.
- Строка — до 100 символов (`ruff` следит).
- Новый инструмент модели: функция с докстрингом Google-style под
  `@beta_tool` и `@guard` — схему SDK соберёт сам.

### Инварианты, которые легко сломать

Каждый из них уже ломался и стоил отладки:

- **Цикл вызова инструментов написан вручную, а не взят из SDK.** Готовый
  ранер не отдаёт ответ по мере готовности, а без этого Джарвис молчит всю
  долгую мысль. Историю ведём сами — она нужна и для диска, и для `pause_turn`.
- **Серверные инструменты выполнять не надо.** Веб-поиск отрабатывает на
  стороне Anthropic; в `_run_tools` попадают только свои.
- **Заглушка Messages API говорит потоком и режет текст произвольными
  кусками.** Куски не совпадают с фразами — иначе нарезка на фразы окажется
  непроверенной.
- **На диск история кладётся простым JSON** через `to_plain()`. Блоки ответа —
  объекты SDK, они не сериализуемы, и без этого память теряется при перезапуске.
- **Системный промпт — три блока от стабильного к изменчивому:** персона
  (кэшируется), факты, обстановка. Кэш промптов префиксный; время суток
  в начале обнуляет кэш на каждом ходу.
- **Порядок инструментов в `build_tools()` фиксирован** по той же причине.
- **История режется по границам ходов.** Срез не должен начинаться с
  `tool_result` — API отвергнет запрос.
- **Фоновый исполнитель не получает `spawn_task`** — иначе одна просьба
  разворачивается в лавину исполнителей.
- **Ход диалога не выполняется в главном потоке.** Главный поток — консоль
  оператора: он должен остаться свободным, чтобы принять разрешение, которое
  запросит сам диалог.
- **Отказ владельца — обычный результат вызова, не исключение** (декоратор
  `guard`). Иначе SDK печатает трассировку на каждое «нет».
- **Личные файлы пишутся через `secure()`** — каталог 700, файлы 600, включая
  промежуточный `.tmp`. Иначе между записью и правами есть окно, в котором
  переписку читает любой пользователь машины.
- **Стирание удаляет файлы, а не содержимое.** Записать пустой список — значит
  оставить прежние байты на диске до перезаписи.
- **Заменённый факт не удаляется, а помечается** `superseded_by`. Молчаливое
  удаление скрыло бы ошибочную замену; так её видно в панели.
- **В промпт и в поиск идут только действующие факты.** Формат памяти меняется
  добавлением полей — старые файлы читаются через `_upgrade()`.
- **Поиск в памяти ранжирует, а не фильтрует.** Требовать все слова запроса
  нельзя: люди спрашивают предложениями, и «что ты знаешь о моей работе» не
  ляжет на факт целиком.
- **Служебные слова отбрасываются до обрезки окончаний.** После неё «когда»
  становится «когд» и в списке служебных уже не находится.
- **Правила разбирают событие раньше модели.** Это приватность, а не экономия:
  разобранное правилом машину не покидает. Модель — только для спорного и
  только в пределах бюджета.
- **Очередь событий лежит на диске.** Сбой возвращает событие обратно, но не
  больше трёх раз — иначе одно битое событие крутится вечно.
- **Хроника имеет срок жизни.** Журнал происходящего без срока превращается
  в досье.
- **Вслух — не больше одного события за такт.** Решение принимается для всех,
  но голос занимает одно; остальное возвращается в очередь. Иначе помощник
  превращается в сирену.
- **Холст карты памяти не пересобирается при обновлении.** Панель перерисовывает
  раздел каждые четыре секунды; для графа это значит потерю раскладки, над которой
  он только что работал. Обновляются данные, а не разметка.
- **Отказ поднимает порог для своего рода событий, а не для всех.** Иначе одно
  «отстань» оглушает Джарвиса целиком.
- **Цвета панели живут в переменных на `:root`, а тёмная тема их переопределяет.**
  Цвет, объявленный только внутри `@media`, в другой теме не существует — это
  классическая нечитаемая страница.

### Тесты

Ключ API и микрофон не нужны: агент прогоняется против локальной заглушки
Messages API, которая проверяет и форму запроса, и цикл вызова инструментов.

Новую логику агента проверять заглушкой, а не моками — так тест ловит и то,
что SDK реально отправит в сеть.
