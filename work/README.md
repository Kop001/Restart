# Рабочая папка

Здесь лежит всё, что не код: тексты, заметки, таблицы, разборы, черновики.

Раскладка простая — по смыслу, а не по типу файла:

```
work/
  <тема>/          один каталог на дело: письмо, документ, разбор
    ...             файлы этого дела
```

Правила ровно два:

- имя каталога говорит, о чём дело, а не когда оно заведено;
- законченное не удаляем — к нему возвращаются чаще, чем кажется.

Ветка и коммиты — как для кода (см. `CLAUDE.md`), но линтер и тесты
здесь не при чём: они про `jarvis/` и `tests/`.
